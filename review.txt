eShopLogistic custom build review: 2.2.20-walls.0.2

Changed files:
- wc-eshop-logistic.php
- Classes/Shipping/Base.php
- assets/js/checkout.js
- Modules/Unloading.php
- views/unloading-form.php
- review.txt

What changed:
- Updated plugin header Version and WC_ESL_VERSION to 2.2.20-walls.0.2.
- Hardened checkout calculation transient handling in calculate_shipping_basic():
  - invalid non-array cached values are deleted and recalculated;
  - cached values without the current delivery type, or with non-array type payloads, are deleted and recalculated;
  - invalid cache is logged as a debug event without address, customer, API key, or cache key data;
  - empty, false, non-array, or structurally invalid calculation responses are not stored in transients;
  - unexpected price shapes fall back to 0 instead of passing arrays/non-numeric values forward.
- Hardened city search AJAX in assets/js/checkout.js:
  - targets are normalized with normalize('NFC'), replaceAll('ё','е'), and trim();
  - requests shorter than 2 normalized characters are skipped;
  - duplicate target/currentCountry/typeFilter requests are not resent;
  - previous in-flight jqXHR requests are aborted before new ones;
  - stale responses are ignored;
  - render callbacks only run for success === true and expected response data shape.
- Stabilized unloading address parsing:
  - getPartAddressNameDoor() always returns region, city, street, house, room keys;
  - getPartAddressNameTerminal() always returns terminal and terminal_address keys;
  - terminal_address falls back to trim($name) even if terminal code is absent.
- Guarded unloading form reads that can be missing for old orders.

Validation:
- node --check assets/js/checkout.js: passed.
- git diff --check: passed, with only CRLF conversion warnings from Git on Windows.
- PHP lint was not run because php CLI is not installed or not available in PATH in this environment.

Risks / manual testing:
- Checkout delivery calculation should be tested with a stale/bad transient and with a normal fresh calculation.
- City search should be tested with fast typing, repeated same query, ё/е input, modal region search, billing city search, and shipping city search.
- Order unloading modal should be opened for old orders without saved ESL debug/address metadata and for terminal/door orders.
- Delivery prices should be checked for services returning price as scalar and as { value: ... }.
